Supabase: غير متصل جميع التعديلات محفوظة

تشغيل Ghomary CRM كتطبيق على الموبايل (PWA)

بعد رفع هذا الملف على استضافة مجانية (مثل Netlify Drop أو GitHub Pages)، افتح الرابط من موبايلك واختر "إضافة إلى الشاشة الرئيسية / Add to Home Screen" ليظهر بأيقونة تطبيق ويعمل بملء الشاشة مع مزامنة سحابية تلقائية.

📱 لأجهزة Android (Chrome): اضغط على القائمة (⋮) أعلى المتصفح ثم اختر تثبيت التطبيق / Install app أو الإضافة إلى الشاشة الرئيسية.
🍎 لأجهزة iPhone (Safari): اضغط على زر المشاركة (مربع به سهم لأعلى) ثم اختر إضافة إلى الصفحة الرئيسية (Add to Home Screen).
